# TypeScript Atlas

日本語で学ぶTypeScript教科書・問題集。

- 解説35章、確認問題70問、記述演習35問、総合演習6題
- 進捗はブラウザーのlocalStorageに保存
- 記述演習は自己採点。コード実行には公式TypeScript Playgroundを利用

## GitHub Pages

このフォルダーの内容をリポジトリのルートに置きます。
Settings → Pages → Deploy from a branch → main / (root) → Save。
ビルドや依存パッケージのインストールは不要です。

## 学習データ

進捗はドメインごとの保存です。別の公開URLでの進捗は自動移行されません。
